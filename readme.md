# 🐘 PHP Learning Repository

This repository contains PHP code, experiments, and small projects that I use while learning PHP.

## Purpose

The goal of this repository is to:

 - Explore PHP language features
 - Learn common PHP libraries and extensions
 - Experiment with web development concepts
 - Test ideas and prototypes
 - Keep a record of examples and lessons learned

## Resources

The repo follows much of the guide available in [PHP the Right Way](https://phptherightway.com).
